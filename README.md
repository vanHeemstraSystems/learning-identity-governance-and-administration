# Learning Identity Governance &amp; Administration 

## Identity Governance & Administration (IGA)
CISSP Domain: Domain 1 - Security and Risk Management, Domain 5 - IAM

### Learning Objectives:
	•	Understand IGA framework components
	•	Learn access certification processes
	•	Explore segregation of duties (SoD) controls
  
### Study Topics:
	•	Identity governance frameworks
	•	Access request and approval workflows
	•	Automated provisioning and deprovisioning
	•	Access certification and recertification
	•	Segregation of duties (SoD) analysis
	•	Role mining and optimization
  
### Assignment:
Develop an IGA implementation roadmap for a 5,000-employee organization. Design access certification processes, SoD conflict matrices, and automated workflow diagrams. Create KPIs and metrics for measuring IGA program effectiveness.
